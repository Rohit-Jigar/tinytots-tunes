API Credentials & Setup Manual

The application is pre-configured with robust offline and free fallbacks so that it runs immediately without paid accounts. To connect production services, configure your .env file:

1. YouTube Data API v3 (Live Publishing)

To publish live to your YouTube Channel:

  1. Go to Google Cloud Console.
  2. Create a project and enable YouTube Data API v3.
  3. Go to Credentials → Create OAuth 2.0 Client IDs (Desktop Application).
  4. Download the JSON file and save it as client_secrets.json in the project root.
  5. Set YOUTUBE_MOCK_MODE=False in your .env file.
2. OpenAI API (DALL-E 3 & OpenAI TTS)

Optional for studio-grade image illustrations and ultra-smooth voiceovers:

IMAGE_PROVIDER="openai"
VOICE_PROVIDER="openai"
OPENAI_API_KEY="sk-..."
3. ElevenLabs API (Neural Voice Cloning)

Optional for expressive singing voices:

VOICE_PROVIDER="elevenlabs"
ELEVENLABS_API_KEY="..."
ELEVENLABS_VOICE_ID="..."
4. Blender Headless Render Path

If you have Blender installed, set the absolute executable path:

BLENDER_PATH="C:/Program Files/Blender Foundation/Blender 4.2/blender.exe"
